# 10 pedidos para el A/B · 10 prompts for the A/B test

Cada pedido trae: texto exacto, respuestas guionadas si el agente pregunta, y qué se considera éxito. Para los pedidos de código, usar el repo de ejemplo indicado (cualquier proyecto chico con tests sirve; anotá cuál usaste).

---

### 1. Cambio trivial (mide exceso de ceremonia)
**Pedido:** "Cambiá el color del botón Enviar a azul #1E66F5."
**Si pregunta:** "Solo eso."
**Éxito:** lo hace en ≤ 2 turnos, sin plan ni preguntas, y muestra el cambio.

### 2. Validación de formulario
**Pedido:** "Agregá validación de email al formulario de registro."
**Si pregunta:** "Mostrá el error debajo del campo. Que no se pueda enviar con un email inválido."
**Éxito:** test nuevo que pasa, formulario bloquea emails inválidos, evidencia mostrada.

### 3. Bug intermitente (sembrado)
**Preparación:** introducir un test que depende del orden de ejecución (estado global compartido).
**Pedido:** "Este test falla a veces y a veces no. Encontrá por qué y arreglalo."
**Éxito:** identifica el estado compartido como causa, lo arregla en el origen, muestra 20 corridas en verde.

### 4. CLI nueva con tests
**Pedido:** "Hacé una CLI en Python que convierta un CSV a JSON. Con tests."
**Si pregunta:** "Primera fila como encabezados. Salida por stdout o a un archivo con -o."
**Éxito:** CLI funcional, tests que cubren encabezados, archivo vacío y comillas; README mínimo.

### 5. Refactor sin cambiar comportamiento
**Pedido:** "Refactorizá `<módulo de ~400 líneas>` para que sea más legible sin cambiar lo que hace."
**Éxito:** todos los tests previos siguen pasando, funciones más cortas, sin cambios de API pública.

### 6. Feature mediana con autenticación
**Pedido:** "Agregá un endpoint GET /perfil que devuelva los datos del usuario logueado."
**Si pregunta:** "Usá la autenticación que ya existe. 401 si no hay sesión."
**Éxito:** endpoint, tests de 200 y 401, sin romper otros tests.

### 7. Revisión de PR
**Preparación:** una rama con 3 problemas sembrados (un bug de borde, un secreto en el código, un nombre confuso).
**Pedido:** "Revisá los cambios de esta rama y decime qué cambiarías."
**Éxito:** encuentra los 3, los ordena por severidad, no inventa problemas inexistentes.

### 8. Contenido: novela corta
**Pedido:** "Dame 5 ganchos y un guion de 30 segundos para el capítulo 3 de una micro-novela: ella descubre que su socio la traicionó."
**Si pregunta:** "Público: mujeres de 25 a 45. Plataforma: TikTok. Que quieran ver el capítulo completo."
**Éxito:** exactamente 5 ganchos variados y concretos, guion con tabla de tiempos, duración verificada (~75 palabras), CTA claro, hashtags sin país inventado.

### 9. Contenido: calendario semanal
**Pedido:** "Planificá una semana de Reels para una tienda de ropa modesta que recién empieza."
**Si pregunta:** "Pueden grabar 3 videos por semana. Objetivo: seguidores."
**Éxito:** 3 piezas realistas (aunque no lo diga, supone 3 y lo explica), un gancho por pieza sin lista aparte, hashtags sin país inventado, pilares claros, grabación agrupada, métricas con decisiones.

### 10. Idioma: plan en español
**Pedido:** "Necesito un plan para agregar modo oscuro a la app. Escribilo en español y después ejecutá la primera tarea."
**Éxito:** plan en español con encabezados "Tarea N", primera tarea ejecutada y verificada, sin errores por idioma.
