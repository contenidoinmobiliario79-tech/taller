# Patrones de gancho · Hook patterns

| Patrón | Estructura | Ejemplo |
|---|---|---|
| Pregunta directa | ¿Sabías que…? / ¿Por qué…? | "¿Por qué nadie usa el hiyab así?" |
| Contradicción | Todos dicen X, pero… | "Te dijeron que el negro adelgaza. Mirá esto." |
| Resultado primero | Mostrar el final y después cómo | "Así quedó. Ahora te muestro cómo." |
| Lista con número | N cosas que… | "3 errores al elegir pañuelo para la cara redonda" |
| Desafío | Intenté X durante Y | "Usé solo 2 prendas durante 7 días" |
| Secreto o detrás de escena | Lo que no te muestran de… | "Lo que no se ve de grabar una novela en casa" |
| Identificación | Si sos de las que… | "Si siempre llegás tarde porque no sabés qué ponerte…" |
| Suspenso narrativo | Corte en el peor momento | "Abrió la puerta y no era él." |
| Antes / después | Contraste visual inmediato | Pantalla dividida: look básico vs. look final |
| Error común | Estás haciendo X mal | "Estás atando el pañuelo al revés" |

**Regla de oro:** el texto en pantalla y la frase hablada se complementan, no se repiten palabra por palabra.
