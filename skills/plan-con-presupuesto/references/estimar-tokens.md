# Estimar tokens · Estimating tokens

Una estimación sirve para decidir, no para facturar. Redondeá hacia arriba.

| Tipo de tarea | Rango típico |
|---|---|
| Cambio de una función con su test | 8k–15k |
| Archivo nuevo de ~150 líneas con tests | 15k–30k |
| Refactor de un módulo de 400 líneas | 40k–80k |
| Investigar un bug sin pista clara | 20k–60k |
| Una tarea hecha por subagente (incluye su contexto) | +15k–40k sobre lo anterior |
| Revisión por un revisor separado | 8k–20k |
| Guion corto + 5 ganchos | 4k–8k |
| Calendario semanal de contenido | 6k–12k |

**Multiplicadores**
- Proyecto que no conocés: ×1,5 en las primeras tareas.
- Tests lentos o con salida larga: sumá 5k por corrida.
- Persona que pide muchos cambios de rumbo: ×1,3.
